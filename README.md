# Adventure Works Data Analysis

## Project Overview
This project focuses on analyzing the Adventure Works dataset to generate meaningful business insights and support data-driven decision-making.

## Tools & Technologies
- Microsoft Excel
- Power BI
- Tableau
- MySQL

## Project Files
- **MySQL:** SQL queries used for data analysis.
- **Power BI:** Interactive business intelligence dashboard.
- **Tableau:** Data visualization and analytical reports.
- **Excel:** Complete project workbook.
